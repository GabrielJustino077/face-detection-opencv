# Detector de Rosto em Tempo Real

Este projeto utiliza Python e OpenCV para detectar rostos em tempo real utilizando a webcam

## Funcionalidades 
- Detecção de múltiplos rostos em vídeo
- Processamento em tempo real
- Aplicação de técnicas básicas de visão computacional

## Tecnologias Utilizadas 
- Python
- OpenCV

## Como executar 
pip install opencv-python
python detector.py
